The ecosystem

Pick the question. Pick the lens.

Every application reads and writes the same markets, so a signal found in one is usable in all the others.

One lifecycle

From a question to a signal.

1

Ask

Anyone creates a market from a question, a set of outcomes and a way to resolve it.

Example · “Which grants get funded?”
2

Trade

People and agents buy the outcomes they believe in. Prices move to the crowd’s estimate.

Example · 48 outcomes, one market
3

Use the signal

A team, a DAO or an investor reads the prices. Seer informs the decision. It never takes it.

Example · the committee shortlists
4

Resolve

Curated resolution settles the market and pays the shares that were right.

Example · winners paid at $1
For builders

The base layer is open.

Markets are built on conditional tokens, wrapped as ERC-20s so any wallet and any DEX can hold them. Anyone can create a market. Resolution is curated through Kleros.

PermissionlessCreate a market for any question with a resolution source.
ComposableOutcome tokens are plain ERC-20s.
Agent-readyQuote and batch-order endpoints for programmatic traders.
CuratedVerified markets are flagged in every interface.
DocumentationGitHub
// create a many-outcome market, then read its prices const market = await seer.markets.create({ question: "Which proposals will reviewers score highest?", type: "multi-scalar", outcomes: proposals.map(p => p.id), collateral: "sDAI", resolution: { source: "reality.eth", curated: true }, }); const prices = await market.prices(); // prices sum to 1. Read them as a ranked signal. // an agent trades the same market in one batch await market.trade([ { outcome: "lantern-rpc", side: "up", size: 250 }, { outcome: "tessera", side: "down", size: 120 }, ]);
